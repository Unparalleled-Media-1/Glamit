# GLAM AI

Global AI beauty, grooming, fashion and lifestyle discovery. Every Look. Every Style. Everyone.

The [Master PRD v2.0](docs/specification/master-prd-v2.md) consolidates the global inclusivity and commerce direction. Its revised architecture/acceptance criteria are proposed for review; current code remains a limited foundation, with no live AI/catalog/payment integrations or age-specific modes enabled.

The approved [architecture and product specifications](docs/specification/README.md) define the product. See [approval record](docs/approvals.md) for authorized scope and remaining release gates.

Production deployment and destructive database changes require explicit approval. No feature is production-ready merely because it is specified.
