# Add an interactive web preview and preserve the past day’s builds on GitHub

The existing application had screenshots but no shareable, self-contained review hub. This change bundles the actual React app into a static preview with phone/desktop switching and all nine review journeys, supports GitHub’s repository subpath, and retains permission-first local photos, original preservation, independent look components and all disconnected authorization/commerce boundaries. The normal Next routes remain unchanged when no preview prefix is configured.

All eight requested historical build snapshots are preserved on matching GitHub branches with verified hashes and a source archive command. A GitHub workflow builds/tests the preview, uploads historical source ZIPs and native JavaScript exports, and attempts Pages publication. Hosting still depends on Pages permissions/settings; local GitHub API calls were Forbidden, so a live URL is not claimed from compilation.

Validation: repository-prefixed static preview browser test (including photo upload/CSP, frame modes, Studio handoff, merchant entry and denied switching); normal Next production build and 10 Chromium journey groups; 8 client/render tests; main/preview TypeScript; React runtime; Ruff lint/format; production dependency audit. Historical archive contents were checked for ignored local files. No default-branch merge, force push, production DB change or live integration activation is included.
