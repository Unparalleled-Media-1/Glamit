# Replace text-led core screens with a visual beauty experience

The prior goal-led app still looked like a set of planning forms compared with the supplied beauty-app references. This change rebuilds Home, Analysis and Studio around portrait-led charcoal/blush layouts: immediate analysis/stylist actions, beauty categories with task routing, campaign/inspiration cards, framed photo-preparation entry and a compact visual editor with reference thumbnails, color families and swatches. An interactive color explorer uses explicitly illustrative palettes. The new assets are original fictional adult portraits with recorded provenance; competitor imagery/claims are not copied.

Tool-specific styling fixes accompany the visual work: Makeup Match no longer offers hairstyles, and selected makeup style/color mood enters the correct Look Builder component while preserving unrelated selections. Existing session/profile consent, editable looks/wardrobe, contextual commerce and canonical server authorization remain unchanged. Reference portraits, swatches and sliders do not generate or alter personal results; provider-backed analysis/try-on, account sync and commerce remain unconnected.

Validation: 10 Chromium journey groups, 27 application captures and an actual-capture visual review sheet; 104 backend tests; 8 shared client/render tests; lint/format, OpenAPI consistency, TypeScript, React runtime, Next build and final iOS/Android Hermes exports pass. Device/human usability, full accessibility and real AI/merchant quality remain open. No dependency/migration change, public Git push, PR publication, deployment or environment publication is performed.
