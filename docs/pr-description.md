# Integrate contextual recommendations and Merchant Snap & List

The analysis-first app previously stopped at uncomputed reports and separate commerce planning. This change embeds recommendation requirements, organic and separately labeled sponsored sections, honest no-match states, saved requirements and Complete the Look across Face, Hair, Skin Appearance, Body & Fit, Color, Makeup Match, Makeover and routines on web/native. Qualified card components preserve unknown totals, show source/condition/expiry and require fresh handoff/quote review; disconnected views contain no invented listings.

Merchant Snap & List adds unchanged local originals, optional enhancement controls, manual factual review, session drafts, duplicate checks, catalog health and bounded web JSON import/export. Native camera/gallery code shares the factual-review rules. Imports discard supplied identity/media/review authority. Authenticated canonical APIs add single/atomic bulk drafts, immutable revisions, separate privileged content approval, publication/withdrawal/rollback, outbox indexing and source/stock/region/currency/market eligibility. Exact matches require a reviewed identifier plus its source organization; every required tag must match. Unknown costs cannot pass a firm delivered-budget check, services require quotes, rentals remain gated and paid placement cannot alter findings.

Leased preparation jobs use an explicitly qualified provider port, stable retry keys, original/derivative separation, declared completed features and merchant review. Failed, stale or revoked results cannot overwrite facts. No provider, private binary store, ad serving, notification, purchase or booking service is connected. Canonical migrations extend the existing history through `0008_catalog_market_policy` with server-only RLS; no runtime country/merchant is seeded.

Validation: 96 PostgreSQL tests, six shared client/rendering tests, lint/format, typed API generation/check, TypeScript, web build and both native JS exports passed. Actual Next.js browser checks and screenshots are recorded in docs/application-preview/test-results.json. Physical-device camera/cache behavior, real provider fidelity, media ingestion/read grants, authenticated client wiring and commercial activation still require the deferred integration/qualification stage. Test fixtures are not live merchants, inventory or AI integrations. No production database migration, Git push, PR, deployment or environment publication is performed.
