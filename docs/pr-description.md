# Build a goal-led GLAM styling journey and controllable profile memory

The previous mobile hero and tool-led forms delayed the first useful action and split styling across disconnected screens. This change puts Face Analysis and Personal Stylist above the fold, adds six goal entries, and connects a shared event/conversation brief to an independent five-component Look Builder, owned-wardrobe reuse and Get This Look. Editing hair preserves makeup/outfit choices; saved looks can be reopened, updated and deleted. First-use and returning dashboards share the editorial identity. Browser navigation is fixed with reserved safe-area space; native uses actual safe-area context.

Profile memory is optional and limited to user-approved device text/selections. Photos, invitation/inspiration files, conversations, credentials, inferred identity and uncomputed reports are excluded; edit, opt-out and deletion are supported. Image/PDF references remain local; no AI answer, official event theme, generated makeover, inventory, confirmed quote or payment is fabricated. Existing server organization/RBAC/catalog truth boundaries remain intact. Account report/profile synchronization, real inference and live product/service matching are deferred.

A central pure server policy calculates the fixed 10% completed eligible item-sale fee and cumulative refund reversal with explicit per-line rounding. Delivery/tax/advertising/service charges are excluded; service commission remains unset. This does not introduce a payment, order or settlement ledger. Source briefs are archived with checksums and a phased gap assessment.

Validation: 104 real-PostgreSQL backend tests, 8 shared client/render tests, 9 Chromium journey groups with 23 screenshots, Ruff lint/format, OpenAPI consistency, TypeScript, React runtime checks, Next build and both native Hermes JS exports pass. Physical-device accessibility/safe areas, human usability, authenticated cloud memory, real AI/matching quality and all commerce/settlement integrations remain unverified. No hosted DB migration, public Git push, PR publication, deployment or environment publication was performed.
