## Implementation

- `services/api/src/glam_api/analysis_passport.py`: current purpose/grant lookup; authenticated read-only storage/model status probe without holding database locks during remote I/O; corrected reports with original AI estimate, certainty, uncertainty and explicit user provenance; versioned idempotent correction writes; existing canonical Style Passport read/selection with revision conflict handling.
- `db/migrations/versions/0017_analysis_passport.{py,sql}`: canonical successor to0016, two private server-only RLS tables, owner/media/job constraints, immutable revisions except one-way privacy redaction, selected correction snapshot ownership trigger, supporting indexes and empty-only transactional rollback. No new profile/passport store, grant elevation, legacy preference overwrite or historical migration edits.
- `services/api/src/glam_api/analysis_privacy.py` and `analysis_jobs.py`: withdrawal/expiry/deletion/cancellation clears dependent correction payloads and unlinks only the affected selected report, incrementing the existing passport revision. The existing worker sweeps remain operational when dispatch is disabled. Minimal opaque audit/revision metadata remains; this is not whole-account erasure or provider deletion.
- `apps/mobile/NativeAnalysisJourney.tsx`, `App.tsx`, `NativePrivatePhotos.tsx`: genuine native controls, two explicit remotely acknowledged consent purposes, owned-cache upload, actual job states/manual status refresh, correction editor, explicit selected-snapshot save, saved-account reload, privacy actions and stale-response/session/unmount fences. Pending/ambiguous actions never become fabricated success. Unsaved edits must be saved before passport approval. Library deletion invalidates the private report view.
- `packages/product/analysis.ts`, `private-media.ts` and native wrapper: generated typed contracts, bounded validated response projection, HTTPS-only credential-safe transport, per-request cancellation/session fencing and actual byte-signature MIME detection (the cache filename does not establish image encoding). No local private report/passport persistence or production test fallback.
- Contract repair: merged0016 used `JobRead`, colliding with catalog `JobRead` and breaking preview TypeScript. Renamed only the analysis model to `AnalysisJobRead` and regenerated contracts; catalog references remain unchanged. Reproduced failure before the change; preview type check now passes.
- CI installs frozen Node dependencies for the backend's integrated workflow tests and routes relevant native/shared contract changes to that suite. Native picker test isolation explicitly excludes the separately exercised journey component.
