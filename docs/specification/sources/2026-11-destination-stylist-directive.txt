## 6. Add this instruction to Codex

GLAM AI — Destination & Weather-Aware Personal Stylist

# GLAM AI — Destination & Weather-Aware Personal Stylist

Add a global AI Destination Stylist to the existing Personal Stylist, AI Studio and marketplace ecosystem.

Users must be able to enter any city, beach, resort, country, landmark or event location, along with travel dates, activities, occasion, budget, personal style, size preferences and optional cultural or religious dress requirements.

The engine must:

1. Resolve destination and local time zone accurately.

2. Retrieve weather forecasts where available; otherwise use clearly labeled seasonal estimates.

3. Generate complete daily outfit recommendations covering clothing, footwear, accessories, hairstyles, makeup and practical weather protection.

4. Offer multiple looks: casual, elegant, luxury, modest, sporty and budget-friendly.

5. Respect user-selected cultural, religious and coverage preferences without inferring religion or identity from photographs.

6. Allow users to virtually preview selected outfits using GLAM AI Studio.

7. Match every recommended item to actual eligible merchant listings, considering price, size, stock, location and delivery feasibility.

8. Support buying before departure, buying at the destination and booking verified tailors or beauty professionals.

9. Show organic recommendations separately from clearly labeled sponsored listings.

10. Generate packing lists and optionally notify users when a forecast change materially affects planned outfits.

11. Preserve GLAM AI's agreed 10% platform commission for eligible completed marketplace item sales.

12. Support web and mobile through shared backend services, APIs and account data.

UX REQUIREMENT:

This must be a premium visual styling experience with destination photography, editorial outfit boards, swipeable looks, virtual try-on and shoppable product cards.

Do not implement it as a text-only chatbot, generic form or spreadsheet-like dashboard.

Integrate it into the existing navigation without adding another primary tab.

Provide screen designs, API contracts, weather fallback rules, merchant matching logic, tests and visual verification before marking the feature complete.

My recommendation: Make Destination Stylist + Event Stylist + Personal Analysis + Virtual Try-On + Local Shopping one connected GLAM AI capability.

That creates a compelling recurring use case: users can return whenever they're travelling, attending an event, shopping for a season or simply deciding what to wear tomorrow.
