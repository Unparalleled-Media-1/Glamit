## Priority 1 — Deliver one complete native consumer journey

Implement and demonstrate:

1. Launch the actual Expo application.
2. Authenticate a test user.
3. Grant the approved analysis consent.
4. Capture or select a photo using native controls.
5. Upload the photo to private storage.
6. Create a durable backend analysis job.
7. Process the job through the approved provider adapter.
8. Retrieve a persisted report.
9. Display the report in the native app.
10. Correct a supported analysis finding.
11. Persist the correction.
12. Update the user's Style Passport.
13. Close and reopen the application.
14. Retrieve the corrected Style Passport.
15. Repeat on iOS and Android.
16. Verify privacy, consent withdrawal and deletion behavior.

Do not use fabricated results or local-only persistence.

Where live provider access is unavailable, complete and test the full orchestration against a clearly identified deterministic test adapter, then leave live-provider qualification pending.

Finish the actual React Native navigation architecture.

## Priority 6 — Maintain strict implementation controls

For every batch:

1. Identify existing requirement and defect IDs.
2. Reproduce the defect.
3. Implement the correction.
4. Add regression tests.
5. Verify persistence and backend effects.
6. Run relevant web, iOS and Android checks.
7. Update the authoritative records.
8. Report exactly what remains.

Do not mark a requirement complete from source presence, mocked responses or successful compilation alone.
