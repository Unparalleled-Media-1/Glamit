## 1. OIDC variables — secure authentication

OIDC stands for OpenID Connect. It is a standard used to verify user identities through an authentication provider.

For GLAM Beauty, OIDC configuration may be relevant to Google, Apple, or another identity provider, or to secure machine-to-machine authentication in your deployment pipeline.

Typical OIDC settings include:

| Variable             | Purpose                                                  |
| -------------------- | -------------------------------------------------------- |
| `OIDC_ISSUER`        | Identifies the trusted identity provider                 |
| `OIDC_CLIENT_ID`     | Identifies the application                               |
| `OIDC_CLIENT_SECRET` | Secret used by certain confidential clients              |
| `OIDC_REDIRECT_URI`  | Where the provider returns the user after authentication |
| `OIDC_AUDIENCE`      | Expected token audience, where applicable                |

These are examples, not confirmed variable names in your repository. Codex must inspect the actual implementation before deciding what to configure.

If GLAM Beauty uses Supabase Auth for Google, Apple and Facebook, much of the OAuth provider configuration belongs in Supabase Authentication rather than requiring a separate OIDC system.
