## 3. Copy-paste Codex audit and remediation instruction

# GLAM BEAUTY — NATIVE MOBILE APPLICATION AUDIT AND REMEDIATION

Audit the actual Expo/React Native applications in apps/mobile for iOS and Android.

This is a targeted verification-and-repair exercise, not another endless platform-wide audit.

Use the existing 140-feature matrix, defect register, native screen inventories and implementation batch reports as the baseline.

## Scope

Audit and verify:

1. Native architecture and compilation.
2. All native screens, routes, buttons and interactions.
3. Authentication, biometric security and account recovery.
4. Camera, permissions, photo lifecycle and consent.
5. Private media, AI analysis and Style Passport.
6. AI Studio, Advisor and saved looks.
7. Digital Wardrobe, personal styling and discovery.
8. Marketplace, checkout, orders and refunds.
9. Professional bookings and creator features.
10. Role-specific merchant and business companion screens.
11. Notifications, deep links and app lifecycle.
12. Privacy, security, performance and accessibility.
13. iOS simulator and physical-device verification.
14. Android emulator and physical-device verification.
15. App Store and Google Play release readiness.

## Mandatory audit methodology

For every native feature record:

- Feature ID.
- Platform.
- Native screen/component.
- User role.
- Expected behavior.
- Actual observed behavior.
- Backend endpoint.
- Persistence mechanism.
- Credential requirements.
- Test evidence.
- Defect ID if applicable.
- Severity.
- Implementation status.
- Verification status.

Classify evidence separately as:

SOURCE EXISTS\
LOCAL TEST PASSED\
SIMULATOR/EMULATOR VERIFIED\
PHYSICAL DEVICE VERIFIED\
BACKEND INTEGRATION VERIFIED\
LIVE PROVIDER VERIFIED\
PRODUCTION VERIFIED

Never count source presence or browser previews as native functionality.

## Required execution

Start with the highest-risk existing gaps:

- Missing CompanionConnection at app entry.
- Missing native navigation stack.
- Persistent photo/analysis pipeline.
- OpenAI Advisor live integration.
- AI Studio generation.
- Native marketplace checkout.
- Notifications and deep links.

For each confirmed defect:

1. Reproduce it.
2. Identify the smallest safe fix.
3. Implement the correction.
4. Add a regression test.
5. Run affected native and backend tests.
6. Verify iOS and Android independently.
7. Update the existing authoritative defect register.

Do not generate a new duplicate feature matrix.

Do not create another HTML mobile prototype.

Do not mark external credential blockers as completed features.

## Security and deployment restrictions

No production database migrations without exact-SQL approval, backup and rollback evidence.

No live Stripe transactions.

No production deployment without authorization.

No fabricated AI results, account approvals or merchant transactions.

No secret keys in mobile or web client bundles.

Preserve approved 10% marketplace commission and existing identity rules.

## Deliverables

Produce:

- Native audit results by platform and role.
- Updated existing feature/defect records.
- P0/P1/P2 issue list.
- Screen-to-API connectivity report.
- Actual iOS simulator evidence.
- Actual Android emulator evidence.
- Physical-device testing gaps.
- Provider activation gaps.
- A prioritized repair sequence.

Proceed with fixes in controlled batches.

The goal is to eliminate implementation defects and achieve genuine native feature completeness, while keeping external-provider activation and production certification as separately reported release gates.

Do not stop at reporting problems. Fix all credential-independent defects within the authorized scope.

Recommended acceptance standard: GLAM Beauty should only be considered ready for public mobile launch when the core Analyze → Results → Style Passport → AI Studio → Discover → Purchase/Booking journeys work on the real native applications, with verified backend persistence and no unresolved release-blocking defects.
