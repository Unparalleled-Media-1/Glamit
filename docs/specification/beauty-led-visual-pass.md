# Beauty-led visual experience

Current UX revision, 5 November 2026 (Africa/Johannesburg). The user rejected the prior goal-led interface as visually behind the supplied Glowup/Glam Up/Dressika screenshots and asked to continue. This revision implements a different visual hierarchy in the actual web/native clients; it does not declare competitive parity, user approval, market readiness or live AI. Existing goal journeys, account/organization/RBAC, consent, saved metadata and catalog truth boundaries remain unchanged.

## Concrete changes

- **Home:** charcoal and blush surface, compact heading, immediate Face Analysis and Personal Stylist, Makeup/Hair/Skincare/Clothing category controls, portrait campaign with task routing, palette/event cards, scrollable inspiration thumbnails, retained six goals and first/returning profile. Desktop uses a campaign/sidebar composition; phone keeps the two primary actions above navigation even at 320×640.
- **Analysis:** editorial face-framing composition with a real entry to permission/local photo preparation. Topic buttons explore Features/Colors/Your guide. It is not an active face scan, live camera feed, recognition or completed report. The selected photo still goes through the existing technical review and uncomputed-result flow.
- **Studio:** portrait-first editor, horizontal mobile tool choices, independent editorial-reference thumbnails, marked-reference control while editing, Rose/Bronze/Berry families and selected swatches, intensity/comparison controls and explicit original reset. Makeup options no longer contain hairstyles. Hair, makeup and outfit directions map to their matching Look Builder component; selected makeup color mood is carried as illustrative text, preserving other components. A chosen reference, swatch or slider does not modify the user's photo. Generation stays unavailable until provider qualification.
- **Color:** interactive reference palette explorer with warm, cool and contrast moods and a color frame. It never assigns a personal color season, undertone, suitability percentage or verified product shade.
- **Assets:** original fictional adult editorial portraits; no borrowed competitor imagery or claims. Optimized source copies and provenance are in [asset manifest](../application-preview/beauty-assets.json). Reference portraits are different adults, never a fabricated before/after.

The public role inventories, event/conversation brief, independent builder, wardrobe, Get This Look, optional text-only device memory, canonical 10% item fee and all existing authorization gates remain. The visual redesign does not connect account synchronization, merchants, analysis, bookings or payments. No private media or appearance attributes are sent to advertising. The latest gap backlog remains [goal-led backlog](goal-led-backlog.md).
