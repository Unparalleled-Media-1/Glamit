# Original illustration provenance

These two sheets were generated for this design review with the session's image-generation tool. They use no supplied brand assets or copied product/reference images.

- `editorial.webp`: four adult editorial portrait concepts with varied styling, complexion, age presentation and modest clothing. Not customer images, inferred identity labels, beauty-analysis output or proof of try-on quality.
- `products.webp`: four unbranded product still-life concepts: tailored layer, shoes/bag, plum cosmetic and accessories. No seller, price, stock, efficacy or delivery claim.

Local PNG source originals are retained outside the checkout in `/workspace/generated_images`; `provenance.json` records their filenames and hashes. Repository copies were encoded as WebP using ImageMagick at quality 86. No semantic image edits were made. CSS displays individual contact-sheet panels; original aspect ratios are retained. Alternative text describes their illustrative role.

Real assets require the corresponding source rights, consent and catalog revision before use. Figma import and native rendering remain unverified.
