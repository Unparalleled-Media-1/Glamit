# Web versus native — implementation boundaries

This is a source-backed native correction, not a new general audit. The authoritative feature matrix/defect register remain the engineering backlog.

The browser galleries and standalone interactive HTML import the web GlamApp. They show responsive web behavior and exact artwork, not Expo rendering, native navigation, an installed binary, camera hardware or live service operations. Their check counts must never be added to mobile completion.

Separate native equivalents exist in App, BeautyExperience, StylingJourney, GoldenCommerce, CompanionViews, CreatorStudio, NativeAccount, MerchantSnapList and ContextualRecommendations. Those use actual React Native components, not a WebView. Visual similarity does not make them browser wrappers. Existing native structure should be repaired incrementally, not discarded for a speculative full rewrite.

| Feature group | Native code exists | Backend/persistence gap |
| --- | --- | --- |
| Home and touch navigation | Native Home and bottom controls | Home personalization is local/user-authored, not verified recommendations; proper native stack/Discover structure missing |
| Photo/analysis | Native picker, consent, quality, results/correction controls | No default consumer API connection, persisted analysis pipeline or connected F1A media client. N1 fixes local picker lifecycle only |
| Studio | Native direction/shade controls and before/after UI | No default generation provider/job connection, actual exact-shade output or persisted generation lifecycle |
| Styling/wardrobe | Native event/destination/wardrobe/look planning controls | Local opted-in metadata exists; invitation inference, genuine AI advice, refreshed weather and outfit synthesis unavailable from root |
| Saved results/Style Passport | Native history/empty states and personalization controls | Saved canonical reports, correction versions, generated looks and Style Passport synchronization missing |
| Shopping/discovery | Native illustrative catalog/detail, contextual matching UI and cart/checkout states | Verified search/stock, durable cart, addresses/tax/shipping, operational orders/returns and end-to-end checkout missing or disconnected |
| Creator | Native signed-in private draft operations via shared Edge contracts | Public discovery/feed, follow/block/report, real social synchronization, shoppable attribution/campaign/earnings incomplete |
| Auth/business | Native account UI, biometrics and organization/workspace state | Real providers and device verification pending; most business panels remain tool inventories/planning, not privileged operations |
| Notifications/deep links | Cold OAuth callback only | Push token registration/delivery/routing, product/analysis/job links, verified universal/app links and supported deferred linking incomplete |

The mobile-first website conversion work is also still application work: contextual Get the GLAM App controls, prepublication fallback, validated stores/QR/smart banners and safe deep links must be implemented in a subsequent scoped batch. No fake listing URLs or promotion that blocks privacy, recovery, support or desktop business operations is permitted.

Screen inventories distinguish source coverage, real backend connectivity, persistence, scoped doubled tests and real-device evidence. Where the broad feature is incomplete, N1 does not close it. Full account export/deletion/retention/legal holds remain F1C, not solved by clearing a local cache.
