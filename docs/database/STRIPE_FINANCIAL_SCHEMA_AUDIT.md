# Stripe financial schema audit

No financial schema, commission/authentication logic, canonical migration or production record was changed. Zanzu Technologies Inc.; approved policy remains 10% on completed eligible physical item amounts after discounts, excluding separately stated shipping/tax. Existing commerce_policy.py governs exact per-line rounding/cumulative refunds. No booking/affiliate fee is approved merely by adding a table. Store integer minor amounts/currency and currency exponent, not binary floats.

Current credit*account/journal/posting are AI-credit accounting; do not reuse them as monetary marketplace ledger. Current stripe_test*\* tables are isolated fixtures/test operations under canonical 0009; that guard refuses non-\_test databases. It must not be removed or stamped through on hosted postgres. Production monetary schema remains proposed and needs dedicated high-risk review after sandbox isolation is resolved.

Future schema separates immutable order price/quantity/discount/tax/shipping snapshots, merchant suborders, account references, verified provider events, payment/transfer/refund allocations, earned/unearned commissions, balanced journal/postings and reconciliation exceptions. Unique provider event and operation keys plus sealed journals enforce idempotency/immutability; refund/commission reversals append compensations. Hold unfulfilled proceeds and freeze disputed transfers. No stored card data, secret API credentials, initiated real payout or automatic settlement accompanies schema deployment.

Actual Stripe fees, balance transactions, transfers and reconciliation remain unverified; user-reported test balance is not commission proof. Existing local sandbox tests exercise success/failure/refunds/disputes/duplicate webhooks/partial fulfillment and zero fixture reconciliation gaps, not authenticated Stripe evidence. Before deployment require tests for per-merchant visibility, server pricing, stock races, cumulative refunds, tax/shipping segregation, unknown remote results, duplicate events and exact external evidence matching.
